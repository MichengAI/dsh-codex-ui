# I001 实施计划

## 输入与输出

输入是 DSH 的会话快照、工作区快照和全文搜索服务。输出是独立加载的客户端侧栏，不改变任一 Host 数据结构。

## 实施顺序

1. 使用官方 `sidebar` 插槽替换默认侧栏，并保留折叠态的展开操作。
2. 通过 `ctx.workspaces.startSession`、`ctx.sessions.open` 和 `ctx.sessions.search` 接入原有行为。
3. 将置顶会话标识保存到浏览器本地存储，并在渲染时从项目分组中排除。
4. 在真实 DSH Web 页面验证加载、搜索、切换、折叠和卸载恢复。
5. 基于 DSH 已有的 `data-chat-anchor-key` 增加会话内轮次导航轨道。

## 风险与回滚

主要风险是 DSH 客户端接口变更。插件不改写默认模块，卸载或从 profile 中移除该插件即可恢复默认侧栏；本地置顶键不会影响 DSH 数据，可单独删除。

## 已采用的兼容方案

技能、插件与连接器菜单现通过 `src/client/settings-navigation.ts` 兼容层直达 DSH 设置分区；该兼容层按可访问名称选择页面，失配时记录告警。待 DSH 提供稳定的设置跳转 API 后替换该层，避免绑定内部 DOM。
