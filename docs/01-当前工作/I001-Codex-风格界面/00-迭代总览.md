## 目标与业务边界

以独立插件交付 Codex 风格的 DSH 侧栏和会话导航体验。安装者不得修改 DSH 源码。第一版将“置顶”定义为工作区置顶；会话轨道定义为当前会话内的轮次跳转。

不在本迭代重写 DSH 聊天渲染、输入框、设置系统或会话持久化。

## 阻塞事项

无外部阻塞。

## 验收标准

- 插件安装后无需修改 DSH 源码即可生效。
- 新对话、打开会话、项目重命名、会话重命名、归档和项目排序均调用 DSH 官方客户端服务。
- 置顶状态刷新后保留，失效或损坏的本地数据不会阻塞侧栏。
- 卸载插件后 DSH 默认侧栏恢复。

## 已完成内容

- 创建 bundle 元数据、`cordis.patch.yml`、构建配置和客户端入口。
- `CodexSidebar` 使用 `sidebar` 插槽替换默认侧栏，提供“新建任务、扩展管理、定时任务、个人助理”导航；定时任务仅为禁用占位。
- 原生 `sidebar.workspaces` 重新接管项目、最近会话、搜索、会话重命名、归档和项目菜单等交互；插件不再维护这些会话列表副本。
- 置顶信息仅保存在浏览器本地，作为原生列表上方的项目快捷区；“管理”弹层可勾选或取消置顶项目。
- 原生会话渲染、工具调用、流式输出、权限和模型选择保持不变；通过稳定的 `data-chat-anchor-key` 为当前会话增加轮次跳转。导航默认仅显示短标记，悬停或键盘聚焦显示提问摘要，当前阅读轮次高亮。
- 会话内容列设为 800px，输入卡片增加最小高度、焦点态和阴影，但仍沿用 DSH 原生 textarea 镜像层，因此输入会继续随内容增长。
- 侧栏导航使用 20px 固定图标列，文字及图标共享垂直基线；菜单和重命名弹窗复用 DSH 语义色令牌，改善暗色模式与禁用保存按钮可读性。
- `package.json` 同时声明 DSH 的 peer 与开发期类型依赖；客户端通过官方 `ui-sidebar`、`ui-settings`、`ui-conversation` 的类型合并注册插槽，不再使用 `as never` 或 `as unknown as`。
- 替换侧栏完整声明并渲染 `sidebar.footer.action`，第三方插件可继续注册其页脚动作；增加官方 client test runtime 的兼容测试用例。
- 文案改由 `michengai.codexUi` 的中英文词典提供；会话锚点和设置跳转的宿主 DOM 兼容代码分别收敛到单一模块，失配时不静默失败。
- 修复主题令牌引用：以 DSH 实际提供的 `label-primary`、`label-secondary`、`label-tertiary` 令牌替换失效的 `text-l*` 令牌；侧栏提升到 14px 基础字号，工作区文件夹对齐导航图标列。
- 移除底部独立“归档会话”入口；导航与工作区图标向左对齐设置图标列；置顶菜单使用“取消置顶”文案。
- 按实测设置图标左边界 16px 再次校正导航与工作区图标左边界。
- 最近列表、子 Agent 过滤和项目/会话弹窗完全复用 DSH 原生实现。
- 移除插件自带技能目录和 Host 接口，技能入口仅跳转 `@michengai/dsh-skills-manager` 的管理页；专家入口跳转 `@michengai/dsh-agency-agents` 的管理页。两个包均声明为可选 peer，缺失时会显示安装提示。
- 侧栏“插件”直达 DSH 原生插件设置；“连接器”按当前会话可用的 MCP 工具目录聚合展示，且不暴露地址、命令或凭证；底部“归档会话”直达归档列表。
- 已验证当前会话读取到 22 项已安装技能，置顶/项目/最近分区、插件跳转和连接器空态均正常。
- 测试纳入 `tsc --noEmit` 类型检查；补齐 `@deepseek-ai/dsh-client-ui-settings-general` 的 peer/dev 声明；`vitest` 运行时路径改用 `createRequire().resolve()` 并移除 node_modules 缺失 `.map` 引发的告警。
- 新增全会话管理面板：过滤子 Agent、空白和已归档会话，提供打开、本地置顶与未读、重命名、归档、派生、ZIP 导出、工作区打开、复制和深链操作；实现只使用公开 `sidebar.footer.action`、`ctx.sessions` 与 `ctx.workspaces`，不依赖会话行 DOM 标记。
- 改为自定义工作区树：以 `sidebar.workspaces` 的更低优先级覆盖原生浏览器，保留项目分组、折叠、搜索、悬停、拖拽排序、会话过滤和原生语义色；项目可通过菜单或拖入“置顶”区域置顶，会话扩展操作直接位于各自三点菜单，不再保留独立会话管理面板。
- 顶栏搜索改为可关闭、可键盘操作的全局搜索面板，基于 DSH 会话与工作区快照搜索普通会话，并提供设置页和新建任务快捷入口；工作区内重复搜索栏及项目展开箭头已移除，主导航与工作区之间增加语义分隔线。
- 项目文件夹点击可切换展开状态但不显示额外箭头；会话左缩进收紧，工作区置顶星标不再显示。
- 轮次导航默认仅显示短横线，悬停或键盘聚焦后放大为 32px 高摘要卡片；侧栏品牌标识放大至 24px。
- 轮次导航改为跟随侧栏实际右边界并在视口左侧中部垂直居中，侧栏外仅留 4px；默认显示 14px 细短刻度，当前轮次仅加长到 20px，悬停或键盘聚焦后展开 32px 高摘要卡片；会话状态标记不再占用标题缩进，标题与项目标题对齐；扩展二级菜单左移 4px。
- 移除工作区行的运行/等待状态点；本地未读是蓝点的唯一来源，打开会话会清除该标记。
- 运行中的会话在行右侧显示旋转状态圈，并继续与本地未读蓝点分离。
- 侧栏根容器在浅色主题使用 `#eef7f5`，暗色主题使用 `#1c1f1e`，其余文字、边框与交互状态继续复用 DSH 语义色令牌。
- 侧栏与工作区树统一采用 Codex 风格系统无衬线字体栈；主导航为 14px/500，二级导航和会话标题为 14px/400，分组和时间为 12px，并以宿主主、次、弱文字色保证深浅色可读性。
- 设置面板调整为宽 800、高 1200；窄视口仍限制为距四边各 24px，避免溢出。
- 专家与技能入口可通过设置分区检测对应可选插件是否已加载；DSH 未提供安全的公开安装 API，不能在浏览器确认后自动拉取和安装最新包。

## 待处理事项

DSH 当前没有会话永久删除或撤销归档接口；本插件只展示宿主已有的归档事实，不提供不可用的伪操作。会话置顶和未读是当前浏览器的本地增强，不写入 DSH 会话数据。
