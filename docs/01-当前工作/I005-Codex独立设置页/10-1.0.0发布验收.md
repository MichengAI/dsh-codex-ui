# 1.0.0 发布验收

更新时间：2026-09-08 23:35（Asia/Shanghai）

状态：已完成

用户明确授权将 UI 升级到 1.0.0，提交、推送并发布。此前 0.2.114 为本地待发布版本，直接并入 1.0.0，不额外发布 0.2.114。用户追加要求安装器一起升级到 1.0.0；UI npm 发布成功后，由既有安装器工作流通过显式 version=1.0.0 锁定官方最新成员。该里程碑特例不改变后续常规 patch 递增。

## 发布范围

独立设置页、公共插槽兼容、全局搜索入口、焦点及引导隔离、配置文件失败反馈、导航图标区分、退出动画闪烁修复。中英文 CHANGELOG 为 Release 正文唯一事实源，中文在前、英文在后。

## 验证与边界

发布前执行完整 pnpm test，远端 CI 与标签工作流再次验证。1.0.0 本地完整检查通过：147 个用例、33 个断言、57 组布局与 4 条退出动画检查，含类型检查及构建。

浅色主题、首次使用引导全流程、配置保存和连接重试仍有宿主实机待验收项；1.0.0 版本号不代表这些路径已完成验证。I005 保持进行中，待办继续有效。
