# 桌面透明设置侧栏重叠

更新时间：2026-09-09 18:27（Asia/Shanghai）

原因：Mica 设置背景透明，被隔离侧栏只有祖先声明 `visibility:hidden`；会话展开容器显式声明 `visibility:visible`，后代重新显示。

修复：仅 Mica 模式且设置页存在时，对原有 inert 分支及全部后代设置 `visibility:hidden!important`，不卸载会话、不改变布局。退出后原选择器失效。
