## 对照结论

1. 字体：沿用系统中文字体栈，标题 24px/600、导航和设置名 14px，说明 12px。源图中文字的实际字体与抗锯齿未知，预览边缘渲染差异属于 P3，不以图像文字替代真实文本。
2. 布局：侧栏实测 240px，正文卡片实测 768px；正文居中，内容标题与卡片左边缘对齐。设置分组间距 44px，卡片圆角 16px。
3. 色彩：深色页面 #181818、侧栏 #202322、卡片 #232323、边框 #333；文字和辅助文字使用独立 tokens。浅色采用白底和浅灰导航、卡片。
4. 图标与图像：使用项目现有 lucide-react 图标库；参考画面无需要生成的插画或摄影素材。图标并非 Codex 专有图标逐像素复制。
5. 文案：分类按本产品能力组织，保留模型、插件、专家、技能、连接器、自动化、归档等入口；不添加 Codex 独有的 Git、Worktrees 等假功能。
