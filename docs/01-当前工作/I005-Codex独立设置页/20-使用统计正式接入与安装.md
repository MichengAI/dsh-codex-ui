## 产品行为

设置的“记录与应用”新增使用统计。侧栏费用入口在该分区可用时跳转使用统计；费用插件未注册时不接管旧入口。页面使用原费用插件 1.0.42 的 UsageBilling 组件与原始 client.js，并未重绘概览、账单、用量、趋势、费率或设置。

iframe 加载同源专用承载页，不加载第二份完整 DSH，也不含预览空数据。原组件自己调用费用插件已有接口。承载层只提供 React/基础控件环境、原入口注入的模型查询、原词典与共享预算状态；原插件文件未经修改。

通过注册相同 store handle 复用宿主已存在的预算实例，避免两个独立预算 store 覆盖彼此。原弹窗仍在 iframe 自己的文档中挂载，关闭通知设置退出；失败时提供重试和打开原弹窗。

## 同源资源协议

以下路由仅允许 GET/HEAD，无请求体；四条均先调用原有 connection.requestRejection，沿用 Host/Origin/登录检查：

| 路径 | 响应 |
| --- | --- |
| /api/dsh-codex-ui/usage/frame | HTML 承载页 |
| /api/dsh-codex-ui/usage/frame.js | 独立 React 承载脚本 |
| /api/dsh-codex-ui/usage/frame.css | 原基础控件样式 |
| /api/dsh-codex-ui/usage/plugin.js | 当前 profile 已安装费用插件的原始 client.js |

未认证返回 401，不可信请求 403，认证能力不可用 503，不支持的方法 405，缺少资源或插件 404。成功返回对应 MIME、no-store、nosniff 和限制 frame-ancestors 为同源的 CSP。无新增统计 API，无代理真实账单请求。
