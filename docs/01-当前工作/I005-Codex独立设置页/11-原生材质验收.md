# 原生侧栏材质验收

更新时间：2026-09-09 00:00（Asia/Shanghai）

## 目标与实现

用户确认同时修改 Desktop 与 UI，让系统材质受桌面壁纸影响，普通浏览器保留实色回退。Windows 11 22H2（build 22621）及以上启用 Mica；其他平台与旧 Windows 保留原桌面背景。这里采用壁纸染色的 Mica，不代表透视桌面后方每个窗口的实时内容。

Desktop 主窗口、标题栏和 DSH WebContentsView 贯通透明背景；受限 preload 通过 data-dsh-native-backdrop=mica 提供样式能力标记，不新增网页原生控制接口。独立关于、快捷键和桌面设置窗口保留实色。

首页与设置导航共用背景、文字、图标及悬停变量。原生模式侧栏叠加 18% 深色或白色表面，正文保持不透明；浏览器浅色回退 #eef7f5，深色回退 #1d2120。没有根据窗口尺寸人为切换颜色。

设置打开期间仅隐藏其底层 inert 内容的视觉，保留挂载和会话状态，避免首页文字穿过半透明导航；关闭后恢复显示。

## 已执行验证

- UI：26 个 Vitest 文件、147 项用例、33 个断言脚本、45 组工作区及 12 组侧栏布局检查通过；类型检查和构建通过。
- 浏览器：原有 4 条退出检查及新增深浅主题原生标记、实色正文、浏览器回退、背景隐藏与退出恢复检查通过。
- Desktop：构建及完整 node:test 命令成功退出（dot reporter），平台支持边界已加入测试。
- Windows 10.0.26200 / Electron 44.1.1 原生独立预览：使用真实构建的 DSH preload、透明 WebContentsView 与生产设置组件，在深浅主题各检查 1280×820、1800×1000 两种窗口尺寸。html/root 为透明；导航分别 rgba(20,23,22,.18)、rgba(255,255,255,.18)；正文分别 #181818、#fff。
- 深色局部并排取样：用户 Codex 约 (26,35,33)，本机预览约 (29,35,33)。壁纸、系统合成及焦点状态会影响最终像素，不能宣称所有环境固定 1:1。

## 尚未验收与兼容边界

- 正式安装后的完整 Desktop 标题栏、首页与设置往返、最大化/还原、配置保存和引导全流程仍需宿主验收。未更改用户正在运行的应用。
- 宿主正文隔离目前依赖 AppFrame 的 root/sidebar 插槽层级及 CSS 模块 _centerCol/_detailsCol 后缀；上游布局变化需重新检查，不能仅靠预览证明兼容。
- 未安装壁纸社区插件，原有玻璃兼容分支未改；原生 Mica 与第三方玻璃组合尚未实测，不修改社区插件内部样式。
- UI 与 Desktop 需要同时安装才能看到原生材质；只升级其中一端时保留实色内容是预期兼容行为。

## 恢复

本轮没有迁移数据或修改 profile。撤销两仓库本轮材质代码并重新构建即可恢复旧外观；以后安装前需保留对应 Desktop 安装资源及 profile 依赖备份，不可只改版本声明代替恢复。
