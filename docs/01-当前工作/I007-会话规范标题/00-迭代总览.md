# I007-会话规范标题

状态：已随 1.1.8 发布。后续侧栏树展开、隐藏删除、会话移动不在本迭代，见 [当前状态](../../00-交接入口/02-当前状态.md)。

负责人：Codex。

优先级：P1。

更新时间：2026-09-16（Asia/Shanghai）

## 目标

新会话在第一条用户消息后，按 `emoji 类型｜主题` 自动命名一次，例如 `⚡ 优化｜批次文字显示`。不写日期。中英文 locale 用各自类型词。手动改名不再覆盖依赖宿主 `rename()` 把来源钉成 `user`，以及 `first-prompt` 只在第一条、尚无标题时调度；本插件不另加守卫。

## 做法

- `cordis.patch.yml` 停用官方 `session-title-llm`，不关闭 `session-title` 服务。
- Codex UI 注册自己的 `first-prompt` 提供方；模型只出 `类型｜主题`，插件再按类型加上固定 emoji。
- 类型词走 `sessionTitle.type.*` 词典，中英分开，不再写死中文。
- 解析前把 ASCII `|` 和 `│` 收成全角 `｜`。stream 按块组装，`block-end` 覆盖 delta，避免正文收两遍。
- 失败或缺少依据时保留宿主回退标题。不改旧会话，不处理 fork、定时、频道、subagent。

## 验证

- 单元测试覆盖类型校验、表情拼装、特殊会话跳过、提供方注册与失败回退。
- 隔离宿主只核验安装产物：`cordis.patch.yml` 已停用 `session-title-llm`，bundle 含 `michengai-codex-ui-session-title`。不在隔离环境调用付费模型。
- 已随 Codex UI 1.1.8 发布。真实模型命名质量仍以本机重载后的新会话为准。
