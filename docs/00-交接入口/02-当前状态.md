## 本轮已完成

- 文件夹折叠状态刷新后持久化，工作区、频道和定时任务使用独立存储键；损坏或不可用的存储安全回退为默认展开。
- 定时侧栏加入列表/概览、任务设置与整组归档；普通会话即使标题形如 `YYYY-MM-DD HH:mm - ...` 也不会被误分流。
- 整组归档会继续处理全部会话，只清理成功项的置顶/未读状态，并保留失败项供重试。
- 任务设置请求增加运行时 schema 校验，设置跳转等待窗口由 1.5 秒增至 4 秒。
- 会话菜单存储统一走有异常保护的 `browserStorage()`。
- Explorer Host 路由限制为已注册工作区根，拒绝盘符根、UNC、相对路径、子路径及无关绝对路径。
- 重型 DOM 兼容观察改为只在相关顶栏、用户消息或设置控件发生变化时按帧处理；不搬移宿主 React 节点。
- `pnpm test` 运行全部 Vitest 行为测试、类型检查、构建和断言脚本；push/PR 与 tag Release 均有测试门禁。
- 安装器固定 UI `0.2.89`、Archive `0.1.16`、Skills `0.1.25`、Agency `0.1.21`、IM `0.1.24`、Automation `0.1.21`，并校验 `DSH_BIN` 的 Windows shell 边界。
