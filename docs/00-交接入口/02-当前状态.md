## 当前实现

- 工作区树：项目/分组/最近，当前会话所在文件夹自动展开；无归档删除能力时不出现删除。
- 会话可移动到其他项目；工作目录随目录一起改写。0.1.6 走官方 persist handle。
- 新会话首条用户消息后按 locale 命名一次；宿主钉死后不再覆盖。标题提供方由独立 `@michengai/dsh-codex-ui/session-title` 插件注册，卸载时回收。
- 会话行右侧显示紧凑相对时间；悬停或菜单打开时让位给归档快捷图标。截断标题在悬停时滚动全文。
- 运行指示灯和完成后未读优先读 `useSessionStatus`（`running` / `completionUnread`），没有再回退 `SessionSummary.running` 和本地 running 边沿。
- 打开会话失败时保留当前全局面板。全局面板打开时不把主视图会话标成选中。
- 连接器 Prompt：有 `uiWorkspace.openWorkspace` 时只走它（内部已 connect + beforeOpen）。没有再 `connectWorkspace` + `openConversationWithDraft`。不要两路连开，否则会多一个空会话。
- 设置「插件配置」转交官方 `plugins.item` / `bundle.config` / `row.config`，绑定 `hooks` 与 `keyedHooks`，文案转发插值参数。
- 设置页和用量统计挂到 `document.body`，避免收缩窄轨的 transform 包含块困住全屏页。
- 侧栏底部按 slot id 逐条 `renderSlot`；每次调用各自一个 `data-slot` 锚点，无 id 的动作丢弃。`.dcu-footer-actions` 保持竖排，不要改成横向 flex。
- 关于页、费用承载、附件草稿、全局面板、官方轮次导航与输入建议列表沿用已发布行为。
- Peer 已声明 rc.1 / rc.2 / 0.1.6-alpha.1 / 0.1.6-alpha.2。开发依赖钉在 0.1.6-alpha.2；`dsh-client-runtime` 无 0.1.6 包，仍用已发布最高版 0.1.1-rc.2，peer 显式 `|| 0.1.1-rc.2`。
- `pnpm-workspace.yaml` 的 `packageExtensions` 为官方 primitives 补 `simple-icons@16.31.0`（alpha.2 只在其 devDependencies 声明），以及 markdown/shiki 依赖，给 vitest 用。正式包补全后应删除。
