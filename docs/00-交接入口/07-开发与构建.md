# 开发与构建

更新时间：2026-08-15 14:16（Asia/Shanghai）

本插件为双面 DSH 包：Host 半（`src/index.ts`）提供只读目录路由，Client 半（`src/client/index.ts`）替换侧栏与设置分区。

## 依赖策略

- 运行时依赖全部以 `peerDependencies` 声明，由 DSH 宿主提供（React、`@deepseek-ai/cordis` 及各 `@deepseek-ai/dsh-client-*`）。
- 开发期以 `devDependencies` 固定公开 npm 的 DSH `0.1.0-rc.6` 客户端包用于类型检查与测试。
- 客户端 bundle 通过 `deps.neverBundle` 复用宿主 React 与 UI 原语，不内联第二份 React。

## 构建

```powershell
pnpm build
```

先执行 `tsc --noEmit` 对 `src` 与 `tests` 做严格类型检查，再由 tsdown 产出：

- `dist/index.mjs` / `dist/index.d.mts`：Host 半入口。
- `dist/client.js`：Client 半 bundle，以 `window.__ModuleLoader__.load({ id, factory })` 握手注册。

## 测试

```powershell
pnpm test
```

包含两类：

- 纯函数断言（`tests/*.assert.ts`）：经 tsx 运行。
- 插槽集成测试（`tests/client-runtime.integration.spec.ts`）：经 Vitest + jsdom 驱动官方 client test runtime。

集成测试通过 `tests/runtime-client-facade.ts` 加载真实发布的 `@deepseek-ai/dsh-client-runtime` 的 client bundle，再交给 `SlotTestRuntime` 验证插槽注册与声明。

## 约束

- 客户端插槽注册使用官方声明合并类型，禁止 `as never` / `as unknown as` 绕过。
- 内部 DOM 兼容读取收敛到 `settings-navigation.ts` 与 `conversation-dom.ts`。
- 新增依赖需同时维护 `peerDependencies` 与 `devDependencies`，并执行 `pnpm install` 重建锁文件。
