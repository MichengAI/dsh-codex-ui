# 项目概览

更新时间：2026-08-15 00:07（Asia/Shanghai）

## 定位

`dsh-codex-ui` 是 DSH Web 的独立客户端插件，将默认侧栏替换为 Codex 风格导航，同时复用 DSH 的会话、工作区和全文搜索服务。

## 当前阶段

I001 进行中，已完成最小插件骨架和左侧导航第一切片。

## 核心能力

- 新建会话。
- 会话内容搜索。
- 会话置顶与浏览器本地持久化。
- 按 DSH 工作区显示会话。

## 稳定边界

- 不修改 DSH 源码、会话日志或工作区数据。
- 仅使用 DSH 官方 `sidebar` 插槽和客户端服务。
- 置顶信息仅存在浏览器 `localStorage`，不跨设备同步。
