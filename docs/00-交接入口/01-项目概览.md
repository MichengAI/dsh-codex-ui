# 项目概览

更新时间：2026-08-27（Asia/Shanghai）

## 定位

`@michengai/dsh-codex-ui` 是 DSH Web 的双面插件：Client 侧以 Codex 风格重构侧栏、会话顶栏和设置入口，Host 侧提供受控的连接器目录、依赖管理、工作区偏好与 Windows Explorer 路由。它复用 DSH 的会话、工作区、搜索和插槽服务，不修改 DSH 上游源码。

## 核心能力

- 工作区、会话、频道与定时任务树，以及新建、搜索、重命名、归档、派生、导出和深链操作。
- 工作区置顶由 Host `/preferences` 持久化，并兼容迁移旧 `localStorage`；各树的文件夹展开/折叠状态使用带版本且有异常保护的浏览器存储。
- 定时任务支持列表/概览切换、任务设置桥接和整组归档；定时会话只按自动化会话 ID 前缀识别，不按可编辑标题猜测。
- 设置窗口目标尺寸为 `1000 × 800`，保留 24px 视口边距；连接器、插件、专家、技能、归档、IM 与定时任务按已安装能力接入。
- Windows“在资源管理器中打开”只接受 Host 工作区注册表中的精确根路径。

## 稳定边界

- 不修改 DSH 源码、会话日志或工作区目录内容。
- 不移动 React 管理的宿主节点；兼容适配只做读取、标注、样式或插入插件自有节点。
- 旧聚合 `@michengai/dsh-codex-suite` 已私有化，仅保留迁移源码；推荐入口是轻量 `@michengai/dsh-codex-suite-installer`。
