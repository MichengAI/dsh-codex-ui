# 技术架构基线

更新时间：2026-08-15 14:16（Asia/Shanghai）

- 运行目标为 DSH Web 客户端；开发期对齐公开 npm 的 DSH 客户端包 `0.1.0-rc.6`，运行时依赖全部以 `peerDependencies` 声明并由 DSH 宿主提供。
- 插件通过 `ctx.slots.inject('sidebar', ...)` 等待布局声明后注册同名 `single` 插槽，并完整声明 `sidebar.workspaces`、`sidebar.settings`、`sidebar.footer.action` 三个子插槽，保证官方工作区/设置组件与第三方页脚动作继续可挂载。
- 数据读取使用 `useSessions`、`useWorkspaces`；会话操作使用 `ctx.sessions`、`ctx.workspaces`；技能与连接器目录经 Host 侧的 `/api/michengai/codex-ui/*` 只读路由按当前会话作用域读取，不泄露本地路径、命令或凭证。
- 浏览器搜索必须调用 `ctx.sessions.search`，不得自行遍历或索引消息内容。
- 宿主内部 DOM 兼容读取（会话滚动容器、聊天锚点、设置跳页）必须收敛到 `src/client/settings-navigation.ts` 与 `src/client/conversation-dom.ts` 两个兼容层，失配时记录告警而非静默失败；其余代码不得直接操作内部 DOM。
- 客户端插槽注册使用官方声明合并类型（`PropsRuntime`、`PropsRenderSlots`、`PropsLocale`），禁止 `as never` 或 `as unknown as` 绕过类型。
- 前端依赖保持最小：React 与 DSH 已有客户端接口由宿主模块表提供；客户端 bundle 通过 `deps.neverBundle` 复用宿主 React 实例，不内联第二份 React。
