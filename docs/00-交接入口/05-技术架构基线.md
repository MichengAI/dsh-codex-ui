# 技术架构基线

更新时间：2026-08-27（Asia/Shanghai）

## 装配与依赖

- 包含 Host 入口 `src/index.ts` 与 Client 入口 `src/client/index.ts`；运行时 peer 由 DSH 宿主提供，客户端 bundle 必须复用宿主 React。
- Client 通过官方 slots/services 装配侧栏、工作区、设置与会话顶栏能力；不得用双重断言绕过官方声明合并类型。
- Host 服务在 `src/host-services.ts` 唯一校验并快速失败。目前需要 `webServer`、`agents`、`tools`、`workspaceRegistry`。

## 数据事实源

- 会话、工作区、归档和搜索使用 DSH 服务；浏览器搜索必须调用 `ctx.sessions.search`。
- 工作区置顶以 Host `/api/michengai/codex-ui/preferences` 为事实源；旧 localStorage 只做一次迁移。
- 本地未读、会话置顶和树展开状态允许保留在浏览器存储，但访问必须经过异常保护。
- 自动化会话归属只认 `dsh-automation-session-` ID 前缀；标题不是所有权元数据。

## Host 安全边界

- 写操作检查同源请求、限制 body 大小，并返回脱敏错误。
- Explorer 路由只打开 `workspaceRegistry.list()` 中的精确工作区根；拒绝 UNC、盘符根和越界路径。
- Windows 安装器的 profile、registry 与 `DSH_BIN` 均须在进入 shell 前校验。

## DOM 兼容规则

- 优先通过 slots 和服务完成产品能力；宿主内部 DOM 只用于官方 API 尚未覆盖的兼容适配。
- 允许读取、添加数据标记、应用样式或插入插件自有节点；禁止搬移、替换或接管 React 管理的宿主节点。
- 选择器与兼容读取尽量集中在 `conversation-dom.ts`、`settings-navigation.ts` 及同职责适配模块。
- 观察器优先绑定 `header`、`[data-conversation-scroll]`、设置 dialog 等目标根。为等待宿主懒挂载或整体重建，可保留 document/body 级哨兵，但回调必须只检查连接状态或相关新增节点，并以 `requestAnimationFrame` 合并，禁止对无关流式变更反复全文档扫描。
