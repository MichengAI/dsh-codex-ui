# 技术架构基线

更新时间：2026-09-08 09:24（Asia/Shanghai）

## 装配与依赖

- 包含 Host 入口 `src/index.ts` 与 Client 入口 `src/client/index.ts`；运行时 peer 由 DSH 宿主提供，客户端 bundle 必须复用宿主 React。
- Client 通过官方 slots/services 装配侧栏、工作区、设置与会话顶栏能力；不得用双重断言绕过官方声明合并类型。
- Host 常规业务能力在 `src/host-services.ts` 装配期校验并快速失败；插件装配需要 `webServer`、`agents`、`tools`、`workspaceRegistry`、`sessions` 与 `sessionPersistence`。认证能力 `connection.requestRejection()` 在每次业务请求时动态读取并关闭失败，以便服务暂不可用时返回明确的 503。

## 数据事实源

- 会话、工作区、归档和搜索使用 DSH 服务；浏览器搜索必须调用 `ctx.sessions.search`。
- 工作区置顶以 Host `/api/dsh-codex-ui/preferences` 为事实源；旧 localStorage 只做一次迁移。
- 本地未读、会话置顶和树展开状态允许保留在浏览器存储，但访问必须经过异常保护。
- 输入历史由 Codex UI 独立负责，通过 `conversation.input.dock` 挂载隐藏扩展，使用会话事件、输入状态、`setDraft` 和候选菜单状态；不依赖 BTW。历史按工作区存储在 `michengai.codex-ui.input-history.v1`，旧 BTW 存储仅在新键缺失时导入并保留旧键用于回退。
- 普通输入仅采集挂载后的 `eventSource.change.kind === 'append'` 增量；挂载时建立 `revision` 基线，多实例共用版本去重，完整 `replace` 重新建立基线以兼容计数归零，`replace/prepend` 不回灌历史。未挂载期间的消息不补录，不按最近若干条文本去重，以保留用户有意重发。
- 历史按键只在自身同步 `setDraft` 调用期间抑制 `input` 对游标的重置，通过 `finally` 恢复监听行为；其他输入事件继续退出历史浏览，不使用 `isTrusted` 粗略过滤程序事件。
- 自动化会话归属只认 `dsh-automation-session-` ID 前缀；标题不是所有权元数据。

## Host 安全边界

- Codex UI 自有业务 REST 统一使用 `/api/dsh-codex-ui/*`，服务端与客户端共享 `src/business-api.ts`；旧 `/api/michengai/codex-ui/*` 不注册兼容入口。
- 所有业务 REST 在读取参数或执行操作前调用当前活动的宿主 `connection.requestRejection()`，复用可信 Host、Origin 与登录 Cookie 校验；认证服务不可用时记录诊断日志、返回 503 并关闭失败。发布契约要求 `@deepseek-ai/dsh-client-connection >=0.1.2-rc.1` 与 Cordis `>=4.0.2`；写操作继续限制 body 大小并返回脱敏错误。
- Explorer 路由只打开 `workspaceRegistry.list()` 中的精确工作区根；拒绝 UNC、盘符根和越界路径。
- Windows 安装器的 profile、registry 与 `DSH_BIN` 均须在进入 shell 前校验。

## DOM 兼容规则

- 优先通过 slots 和服务完成产品能力；宿主内部 DOM 只用于官方 API 尚未覆盖的兼容适配。
- 允许读取、添加数据标记、应用样式或插入插件自有节点；禁止搬移、替换或接管 React 管理的宿主节点。
- 选择器与兼容读取尽量集中在 `conversation-dom.ts`、`settings-navigation.ts` 及同职责适配模块。
- 观察器优先绑定 `header`、`[data-conversation-scroll]`、设置 dialog 等目标根。为等待宿主懒挂载或整体重建，可保留 document/body 级哨兵，但回调必须只检查连接状态或相关新增节点，并以 `requestAnimationFrame` 合并，禁止对无关流式变更反复全文档扫描。
