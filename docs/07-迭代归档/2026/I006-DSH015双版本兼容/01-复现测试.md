# 双版本回归复现

更新时间：2026-09-11 01:02（Asia/Shanghai）

在仓库根目录执行完整回归：

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
pnpm test
```

`test:compat` 要求一个已安装且版本固定的 DSH CLI。CLI 自身及其同步官方依赖都必须是目标候选版本，不能只固定 CLI 后让 npm 解析到其他候选版本。此次验证环境已保留在本机 Temp 中；依赖安装使用精确 override，独立于日常全局 DSH。

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
pnpm run build
pnpm pack --pack-destination $env:TEMP
$env:DCU_E2E_TARBALL = Join-Path $env:TEMP 'michengai-dsh-codex-ui-1.1.1.tgz'
foreach ($rc in @('1', '2')) {
  $env:DCU_DSH_BIN = Join-Path $env:TEMP "dcu-runtime-rc$rc-pinned-20260911\node_modules\@deepseek-ai\dsh\lib\bin.js"
  $env:DCU_E2E_VERSION = "0.1.5-rc.$rc"
  pnpm run test:compat
  if ($LASTEXITCODE -ne 0) { throw "rc.$rc 验收失败" }
}
```

入口会检查运行时版本、新建随机隔离目录、安装 tarball 和面板 fixture、验证安装路径没有链接回开发仓库、启动随机端口宿主，然后依次运行真实页面和设置退出检查。认证 URL 仅传给子测试进程。成功或失败均停止所启动的宿主，隔离目录保留供排查；不要把 fixture 安装到日常 profile。

`DCU_E2E_SCREENSHOT` 可选，用于保存最终视口截图。直接运行 `verify-compat-host.mjs` 时还需提供 `DCU_DSH_URL` 和 `DCU_E2E_WORKSPACE`；URL 必须指向安装了此构建与 fixture 的隔离宿主。
