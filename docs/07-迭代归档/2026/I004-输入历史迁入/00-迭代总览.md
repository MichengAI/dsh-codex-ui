## 评审修复

- 根因：初次挂载回放事件窗口，内存 seq 水位在重载后丢失，连续文本去重无法阻止整批历史再次写入。
- 挂载时只建立窗口 `revision` 基线，后续只消费 `append` 增量，多实例共享版本去重；初始窗口、`replace/prepend` 和未挂载期间的输入均不补录。既有持久化历史保留，不自动删除无法区分是否为主动重发的重复文本。
- 补齐 `@deepseek-ai/dsh-client-ui-input-trigger` peer 及契约检查；增加 BTW 包名、顺序和中英文名称断言；忽略根目录 `.pnpm-store`，保留缓存文件。
- 追加兼容保护：自身同步 `setDraft` 派发 `input` 时不重置历史游标，普通文本框与富文本框均可连续上下召回；外部编辑即使宿主草稿镜像滞后也继续重置，不过滤所有非可信事件。完整窗口替换无条件重设 `revision` 基线，模拟计数归零后仍可采集新的追加事件，多实例与重复通知仍去重。
- 测试先行：首轮四条历史回归和 peer 契约、追加的两种编辑器同步事件回归和版本归零回归，均在对应修复前有效失败。当前 18 项输入历史测试通过；全量 `pnpm test` 通过类型检查、96 项测试、构建和 31 组断言。测试覆盖重载、异步替换、前翻、实时追加、重复通知、多实例、重新挂载、合法重发、连续按键和外部编辑保护；锁文件离线校验通过，无需修改。
- 评审修复 `9610307` 已随 `0.2.104` 发布；未执行真实 DSH 页面交互验收。本地 `web` profile 已登记仓库链接并核对构建哈希，交用户重启后测试。
- 发布验收：根包 [npm 发布](https://github.com/MichengAI/dsh-codex-ui/actions/runs/34023083978)、[Release 说明](https://github.com/MichengAI/dsh-codex-ui/actions/runs/34023083934)、[CI](https://github.com/MichengAI/dsh-codex-ui/actions/runs/34023083919) 与 [Installer 发布](https://github.com/MichengAI/dsh-codex-ui/actions/runs/34023125147) 全部通过。官方 npm `latest` 为 UI `0.2.104`、Installer `0.1.21`，安装器六个成员版本与 CHANGELOG 一致；两份正式 Release 的正文均与双语 CHANGELOG 提取结果一致。
