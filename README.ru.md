## Почему выбирают Codex UI 2.0?

В повседневном использовании DeepSeek Harness стандартный интерфейс может казаться перегруженным из-за тесных модальных окон, однообразных тем или потери истории ввода. **Codex UI 2.0 прошел полную архитектурную и визуальную переработку**, объединив **шесть изолированных субплагинов и встроенный менеджер экосистемы** с высокой производительностью и нативной интеграцией:

* 🚀 **Быстрый вызов истории и умное автодополнение**: Интеллектуальное прогнозирование ввода (`Tab` для принятия, `Alt+Вниз/Вверх` для переключения), вызов истории в стиле терминала (`↑` / `↓`) и адаптивные ручки ширины;
* 🪟 **Полноэкранная панель настроек**: Заменяет тесные окна просторной рабочей средой с мягким фоновым рассеиванием Ambient Ground;
* 🎨 **Темы с физическим матовым стеклом**: 13 качественных палитр (включая Codex, Claude, Dracula, Solarized, Gruvbox и Catppuccin), плоский и парящий режимы компоновки mica, 3 предустановки размытия и блики на полу;
* 🧭 **Модульная боковая панель**: Плавное меню-аккордеон и свободная сортировка перетаскиванием; в свернутом виде **на 100% соответствует официальной 56px панели**;
* 🧠 **Умные заголовки сессий**: Семантический анализ первого сообщения для точного именования с поддержкой контекстов до 4096 токенов;
* 🌐 **Полная поддержка всех 8 официальных языков**: Русский, английский, китайский, японский, испанский, французский, немецкий и португальский (`ru`, `en`, `zh`, `ja`, `es`, `fr`, `de`, `pt`) со сквозной адаптацией текстов, контекстных меню и заголовков;
* 🖥️ **Меню окна десктоп-версии**: Встраивание меню помощи в системный заголовок с обновлением вида и безопасным перезапуском приложения и хоста;
* 📦 **Управление экосистемой**: Единая панель для официальных и сторонних плагинов, проверка обновлений и установка в один клик.

## Архитектурная эволюция: почему полный рефакторинг?

### 1. Проблемы линейки 1.x: Технический долг агрессивных переопределений
На ранних этапах развития DSH не было стандартных реестров слотов и официальных компонентов. Версия 1.x полагалась на принудительный перехват узлов DOM и внедрение глобальных стилей CSS.
В результате любое обновление хоста приводило к сбоям интерфейса, а при отключении тем оставались изолированные глобальные переменные.

### 2. Принципы версии 2.0: Полное следование нативным стандартам
В версии 2.0.0 весь старый код переопределений был **полностью удален** в пользу надежной микроядерной архитектуры:
* 🏛️ **Использование официальных примитивов**: Полный отказ от самодельных элементов CSS в пользу официальных компонентов `Switch` и `Button`;
* 🧩 **6 модульных субплагинов**: Четкие границы обеспечивают независимый жизненный цикл и легкий аудит кода;
* 🛡️ **Безопасность fail-closed**: При отключении модуля все его стили и карточки мгновенно и бесследно удаляются из DOM;
* 🔒 **Надежная изоляция профилей**: Корректное разрешение каталогов исключает взаимное влияние конфигураций.

## Архитектура: 6 ключевых субплагинов и встроенный модуль

| ID субплагина | Название | Возможности |
| :--- | :--- | :--- |
| `composer` | **Улучшения поля ввода (Composer)** | Умное автодополнение (`Tab`), история ввода (`↑`/`↓`), память рабочих областей, изменение ширины и карточки задач. |
| `settings-skin` | **Нативная тема настроек (Settings Skin)** | Полноэкранный интерфейс, плавающие карточки опций, фоновая подсветка Ambient Ground и нативный поиск. |
| `theme` | **Темы и эффект стекла (Theme)** | 13 палитр, плоский режим vs парящие карточки Mica, 3 пресета матового размытия и блики на фоне. |
| `sidebar` | **Модульная панель (Sidebar)** | Аккордеон инструментов, сортировка перетаскиванием, отметка о прочтении и строгое следование сетке 56px. |
| `session-title` | **Умные заголовки (Session Title)** | Генерация стандартизированных заголовков по смыслу первого запроса с поддержкой 8 языков. |
| `desktop-menu` | **Меню рабочего стола (Desktop Menus)** | Пункт помощи в строке меню с перезагрузкой страницы и надежным перезапуском хоста. |
| `dependencies` | **Менеджер экосистемы (Встроенный)** | Дашборд сопутствующих расширений, статистика загрузок npm в реальном времени и пакетное обновление. |

## Совместимость с хостом

* **Поддерживаемые поколения**: Семейство DeepSeek Harness `0.2.x` (`>=0.2.0-rc.1 <0.3.0-0`);

## Установка и начало работы

### Вариант A: Установка через агента (Рекомендуется)

Отправьте следующую инструкцию вашему агенту с доступом к терминалу (замените `web` на нужный профиль):

```text
Установи плагин DSH @michengai/dsh-codex-ui в локальный профиль web командой:
dsh plugin --profile web add @michengai/dsh-codex-ui@latest --registry=https://registry.npmjs.org/
Затем выполни dsh --profile web --dump-config для проверки активации и перезагрузи страницу в браузере.
```

### Вариант B: Ручная установка

Выполните в PowerShell или MSYS Bash:

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
dsh plugin --profile web add @michengai/dsh-codex-ui@latest --registry=https://registry.npmjs.org/
dsh --profile web --dump-config
```

После завершения перезапустите экземпляр DSH Web и обновите вкладку браузера (`Ctrl + Shift + R` или `Cmd + Shift + R`).

## Краткое руководство по управлению

| Функция | Инструкция |
| :--- | :--- |
| **Принять подсказку ввода** | Нажмите `Tab`, когда за курсором появится полупрозрачный текст; `Alt + Вниз` / `Alt + Вверх` для смены варианта или `Esc` для отмены. |
| **Настройка режима подсказок** | В **Настройки → Codex UI** выберите режим (Выкл / Только продолжение / Догадка+продолжение) в карточке «Улучшения поля ввода». Для отключения по всему профилю укажите `config.prediction: false` в `cordis.patch.yml`. |
| **История ввода** | В пустом поле ввода нажимайте `↑` / `↓` для циклического просмотра последних 200 сообщений текущей рабочей области. |
| **Регулировка ширины ввода** | Наведите курсор на боковые границы карточки ввода и потяните за синие ручки. |
| **Смена тем и размытия** | В **Настройки → Codex UI** выберите одну из 13 палитр и настройте силу матового эффекта. |
| **Сортировка боковой панели** | Перетаскивайте элементы по вертикали; синие маркеры подскажут точное место для добавления в меню «Еще». |
| **Сворачивание панели** | Нажмите на кнопку вверху боковой панели для перехода к компактному режиму 56px. |
| **Обновление плагинов** | В **Настройки → Codex UI** нажмите **Установить/обновить все** в карточке сопутствующих расширений. |
